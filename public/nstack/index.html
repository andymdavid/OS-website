01 / The idea

The app is the interface.
The backend is your choice.

An application brings the experience. NStack provides the foundation for the data, files and permissions it needs.

Developers build against one backend interface. People and communities choose who runs their NStack: at home, on their own cloud machine, or with a provider.

Nostr supplies a common identity you own, so you can always reach your data and share it with your web of trust.

04 / Familiar foundations

Real applications need
more than a stream.

Structured state, files and identity belong together. NStack brings familiar services into a modular backend for collaborative apps.

A / DATA

Structured records

Postgres-backed application data and shared workspace state, with each application’s tables kept separate.

B / FILES

Storage that fits

S3-compatible file services for the documents, recordings and other assets your application works with.

C / ACCESS

Identity & permissions

Nostr identities and workspace access rules for people, applications and delegated operations.

D / CONNECTIONS · OPTIONAL

Knowledge graphs

Connect information through relationships, so apps and agents can explore how people, ideas and records relate.

E / EVENTS

Nostr relays

Store and deliver signed Nostr events. Apps can publish updates, query past events and subscribe to new ones.

F / FILE DELIVERY

Blossom

Store and retrieve files by their content hash: a fingerprint of the file’s bytes. Runs alongside workspace file storage.

G / GIT · EXPERIMENTAL

GRASP

Git repository hosting with Nostr identity and relay support, in active experimentation.

Choose your modules.

Run the services your apps need. Knowledge graphs are optional, GRASP is experimental, and each service applies its own access rules.

Questions

Good questions.
Straight answers.

Is NStack a hosting company?

No. NStack is open-source software. Run it yourself, share one with your community, or let a provider run it for you.

Can I connect any application?

Apps connect through NStack’s data, file and permission APIs. Existing apps join in by building that integration.

Can I move between hosts?

That’s the point of NStack: your data isn’t tied to one host. Portable export, import and restore between NStacks are on the roadmap.

Does my Nostr key encrypt my data?

Your Nostr key proves who you are and controls what you can access. Encrypting stored data is a separate layer, with encryption tooling on the roadmap — so choose a host you trust with what you store.

Where should developers start?

Clone the repository, run the stack with Docker, and build against the workspace data and file APIs.
